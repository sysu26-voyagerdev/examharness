# scripts/graph-nodes —— 知识图谱的**人工审定表**（构建输入）

`seed/knowledge.json` 与 `seed/knowledge-fusion.json` **不是手写的**，由 `scripts/graph-build.mjs`
从三份真实材料 + 本目录的审定表**确定性重建**：

| 输入 | 位置 | 进 Git 吗 | 用途 |
|---|---|---|---|
| 课标（2022 与 2025 修订） | `data/curriculum/*.requirements.jsonl` | 否（`data/` 被忽略） | 每个知识点的**存在依据**、领域路径 |
| 课标示例 | `corpus/extracted/*.jsonl`、`data/curriculum/*.examples.jsonl` | 否 | 部分知识点的**示例依据**（例 64、例 65……） |
| 中考真题结构统计 | `data/zhenti/structure.json` | 否（`data/` 被忽略） | 题型分布、分值、支持卷数、共现（融合） |
| 人教社教材目录 | 本文件各表的 `chapter` 字段 | 是（本目录） | 年级/章节**顺序依据**（教材未导入仓库，见报告「诚实清单」） |

本目录只放**审定表**（哪个知识点存在、它凭什么存在、它的前置是谁），
所有统计数字都由脚本现算——表里**不许写任何统计结果**，也不许出现真题原文。

---

## 1. 表结构（`*.mjs`，`export const nodes = [...]`）

```js
export const nodes = [
  {
    // 知识点名：**唯一键**，必须是下面清单里的名字（蓝图与构造器用它做键，改名等于毁契约）
    name: '二次函数图象',

    // 年级与章节：年级 ∈ 七上|七下|八上|八下|九上|九下|综合
    grade: '九上',
    chapter: '22.1 二次函数的图象和性质',

    // 课标领域路径：必须是「第四学段」的领域/主题（见课标 jsonl 的 section 字段）
    // 取值只有：数与代数/数与式、数与代数/方程与不等式、数与代数/函数、
    //   图形与几何/图形的性质、图形与几何/图形的变化、图形与几何/图形与坐标、
    //   统计与概率/抽样与数据分析、统计与概率/随机事件的概率、综合与实践
    domain: '数与代数/函数',

    // kind ∈ 概念|性质|运算|关系|应用|思想方法
    kind: '性质',

    // 同义词/常见别名（agent 不必一字不差；search() 靠它兜底）
    aliases: ['抛物线', '二次函数的图象', '二次函数图像'],

    // 前置：[知识点名, **依据**]。依据必须写清是哪一种：
    //   「课标要求先于」/「教材章节先于（八下19章 → 九上22章）」/「定义依赖」
    prereq: [
      ['一次函数', '教材章节先于：八下第19章在九上第22章之前'],
      ['配方', '教材章节先于：九上21.2 解一元二次方程（配方法）在22.1 之前'],
      ['平面直角坐标系', '教材章节先于：七下第7章在八下第19章、九上第22章之前'],
    ],

    // 课标依据：每条 = 一条**原文里的连续子串**（脚本拿它去匹配课标 requirement）
    // 必须逐条在 data/curriculum/课标2022.requirements.jsonl 或 课标2025修订.requirements.jsonl
    // 的「第四学段」里真的能匹配到；匹配不到的会被脚本记为「推断」并在报告里列出来。
    curriculum: ['能画二次函数的图象', '知道二次函数系数与图象形状和对称轴的关系'],

    // 真题统计的匹配词：**必须是 data/zhenti/structure.json 里 questions[].keywords 里真实出现过的词**
    //（词表来自 scripts/zhenti_stats.py 的 KEYWORD_RULES；不要自己发明新词）
    // 聚合节点可以不写，改用 parts。
    zhenti: ['二次函数', '抛物线', '函数图象', '顶点坐标', '对称轴'],

    // 常见问法：**一句话归纳**（不是抄题面）。允许归纳，但必须与上面的统计相符。
    ask: '先由条件求解析式，再求顶点、对称轴，或判断增减性、最值',

    // 可选：
    // role: 'leaf'（默认，参与共现统计）| 'aggregate'（容器：统计=其 parts 的并集，不参与共现）
    //        | 'fusion'（综合题节点：自带关键词，不参与共现统计）
    // parts: ['子节点名', ...]   // 仅 aggregate 用
    // note: '无直接课标条目，如实说明依据来自哪里'  // 依据不足时**必须**写
  },
]
```

### 硬规矩

1. **不许改清单里的名字**，也不许新增清单外的名字（脚本会对不上就报错）。
2. `zhenti` 里的词必须是真题关键词表里真实出现过的词；**不许把题干句子写进来**（版权红线）。
3. 前置边必须有依据；实在找不出依据的边，**别写**，并在 `note` 里说清楚。
4. 没有课标条目支撑的节点，`curriculum: []` + `note` 写清"依据来自哪里（教材顺序/真题统计）"。
5. 文件是 `.mjs`，只 `export const nodes`，不要 import 任何东西、不要写统计数字。
