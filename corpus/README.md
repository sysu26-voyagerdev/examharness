# corpus/ —— 真实语料放这里（**不进 Git**）

这个目录是给**真实题库 / 教材整理件**用的：它们只是参考材料，用来对齐风格、估难度、
建错因库、以及**查重的对照集**。

> **红线（ADR-0014）**：语料里的原文一律**不对外展示、不对外分发**。
> 产品对用户只显示**数字**（原创度、相似度），原文只作内部参考。
> 所以：`corpus/*` 已在 `.gitignore` 里，只有本文件会进仓库。

---

## 放哪儿

```
corpus/
├── questions/      题库：真题、教辅题、期末卷……（按来源分文件）
├── textbooks/      教材/教参整理件：只用于对齐表述风格
└── knowledge/      知识点清单（这个**可以进 Git**，见下）
```

**建议先接一小份高质量的**：一个年级、一个学期的真题 + 一份知识点清单，跑通再加量。
9–10G 对当前目标没有额外价值，反而拖慢索引——语料是"风格与错因"的来源，不是越多越好。

## 支持四种格式（纯文本，不需要额外依赖）

**`.jsonl`** —— 每行一个对象，最推荐：

```jsonl
{"stem":"已知抛物线 y = x² - 4x + 3 与 x 轴交于 A、B 两点，求线段 AB 的长。","answer":"AB = 2","knowledge":["与坐标轴交点"],"type":"解答","difficulty":0.72}
{"stem":"……","knowledge":["对称轴","顶点式"],"distributable":true}
```

**`.csv`** —— 表头固定：

```csv
stem,answer,knowledge,type,difficulty,distributable
"已知抛物线……","AB = 2","与坐标轴交点","解答",0.72,false
```
（`knowledge` 多个用 `/`、`;`、`、` 或 `|` 分隔；`distributable` 只有写 `true` 才算可对外）

**`.md`** —— `## ` 开头的行当题干，其后内容当答案/解析：

```md
## 已知抛物线 y = x² - 4x + 3 与 x 轴交于 A、B 两点，求线段 AB 的长。
令 y = 0 得 x = 1 或 3，故 AB = 2。
```

**`.txt`** —— 每行一道题。

**PDF / 扫描件**：请先 OCR 成上面任意一种；这条流水线还没写（别指望它当天能用）。

## 知识点清单（`corpus/knowledge/`，**这个可以进 Git**）

知识点**+ 前置关系**就够，**不需要教材正文**。《义务教育数学课程标准（2022 年版）》是公开的，
教材目录也是公开的——用它们整理出来的清单不涉及版权，而且比正文干净。

格式与 `seed/knowledge.json` 一致，可以在 `cordis.yml` 里用 `paths` 追加多个文件：

```json
{
  "nodes": {
    "与坐标轴交点": { "prerequisites": ["二次函数图象"] },
    "动点问题": { "prerequisites": ["最值", "与坐标轴交点"] }
  }
}
```

## 接上之后怎么用

```bash
pnpm build && node bin.js     # 启动时自动扫描并索引
```

- 查重闸门会自动把「与语料库的最高相似度」写进每道题的证据 —— **这就是原创度报告**；
- `ctx.corpus.stats()` 能看到各来源条数。原文永不外泄，只有数字出得去。
