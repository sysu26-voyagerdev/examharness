# 命题组 · ExamHarness

> 初中数学的**原创命题与组卷**系统。题目由**构造**产生、由**闸门**放行、由**教师**签字。

**状态：方案阶段。** 尚未开始正式实现。仓库里目前只有设计文档和一张界面布局草图。

---

## 这个项目是什么

老师给一份**命题蓝图**（双向细目表），一支 AI 命题组按蓝图构造原创题——每题带题干、答案、解析和图形，**正确性有证据、原创度可查、难度有估计**；老师只做终审和局部微调。

它和"题库拼卷"的区别只有一条，但是根本的一条：

| | 常见做法 | 本项目 |
|---|---|---|
| 题从哪来 | 从题库里检索、拼装、改写 | 在可控数学空间里**构造**，结论按构造为真 |
| 对不对 | 让模型再解一遍，或相信它 | 符号计算验证 + 回译比对 + 闸门链 |
| 出错时 | 静默输出错题 | 拦在门外，标"待复核"或直接拒绝 |

## 看那张布局草图

那只是**视觉契约**（布局与措辞的参照物，静态示意）。真正能用的界面在 `client/`（React + Vite）：

```bash
pnpm install
pnpm start          # 构建全部 + 起服务，界面在 http://<本机IP>:8787/
```

开发前端时：`pnpm dev:client`（vite 5173，`/api` 代理到 8787），另开一个终端 `node bin.js`。

## 三条不变量（任何实现都不得违反）

1. **数学真值来自构造与符号计算，不来自模型文本。**
2. **没经过闸门的题进不了题库**——题库只有唯一写入口。
3. **教师是命题者，AI 是命题组**；系统不替老师做决定，只提供证据与建议。
