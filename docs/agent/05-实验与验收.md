# 05 · 实验与验收

> 方案阶段最该做的不是功能，是**实验**。本文定义"怎么算做对了"。

---

## 1. 核心指标：可用题产出率

**可用** = 无需改动题干 / 答案 / 解析即可直接入卷（仅可改字词）。

| 指标 | 含义 | 目标 |
|---|---|---|
| **可用题产出率（主指标）** | 可用题数 / 生成题数 | ≥ 70% |
| 符号校验通过率 | sympy 验证通过的题占比 | ≥ 95% |
| 回译一致率 | 题面忠实编码结构的占比 | ≥ 90% |
| 超纲拦截率 | 构造的越界题被拦下的占比（含故意注入） | 100% |
| 查重 | 与原题库最高相似度 | < 0.20 |
| 人工抽检正确率 | 教师/组员抽检的答案正确比例 | ≥ 95% |

**判定协议（避免自己给自己打分）**：双人独立判定，一人是命题者、一人不是；不一致的交由第三人裁决，并记录一致性（Cohen's κ 不必算，但要报分歧数）。

---

## 2. 四条假设（H1–H4，比功能更该先做）

**H1（杀手实验）**：**构造优先 vs 直接让模型写题**，在同一批题位上比"符号校验通过率 / 可用题率"。
→ 产出一条对比曲线 = PPT 上最有力的一页。它证明的是**路线**，不是一个产品。

**H2**：**往返测试能抓住序列化错误**。故意注入 N 个错误（改数值、删条件、换单位、漏"a>0"），看回译检出的比例。
→ 报检出率与漏检类型。

**H3**：**可用题产出率**。按 §1 协议人工判定 50–100 题。
→ 报主指标 + 分歧数。

**H4**：**图形规范校验器能拦住"误导性图形"**。构造若干"看起来相等其实不等"的图，看拦截率。
→ 这是别人没有的东西，即使拦截率不完美也值得报。

**每条实验都要报"没做到的"**——如实写失败项比全绿更可信。

## 4. 里程碑（到 10/8 平台提交为止）

顺序由依赖决定，每天的产出都应是"能跑的一环 + 一个可测量的数字"。

| 日期 | 目标 | 可验证产出 |
|---|---|---|
| 10/2 | 仓库初始化、Schema 定稿、`cordis.yml` 空转跑通 | `npx` 能起服务，界面能打开 |
| 10/3 | 题库小样入库（300–500 题）+ 知识点图谱 + 检索 | `bank.search` / `graph.prerequisites` 可用 |
| 10/4 | **构造 → 序列化 → 回译 → 符号校验 → 重做** 闭环 | H1、H2 的第一版数字 |
| 10/5 | 图形渲染（数据同源 + 断言）+ 组卷（蓝图约束）+ 查重 | H4 数字 + 一份符合蓝图的卷子 |
| 10/6 | 界面（卷子 / 知识网络 / 证据三视图）+ 导出 Word | 老师能独立完成一次出卷 |
| 10/7 | 批量评测 + demo 视频 + 作品说明 | §3 表格填满 |
| 10/8 | 材料上传（**勾选"中山大学赛区"**）、申报书签字（保险日） | 提交成功截图 |

> **申报书怎么签（2026-10-04 按中大学工通知核对）**：通知"五、线上提交材料"写明——
> **教职工参赛加盖所在院系或单位公章，学生团队仅负责人签字、无需盖章**。
> 我们是学生团队（大学生 OPC 赛道）：**只由主持人本人签字**，"所在单位主要负责人签字（签章）"那一行不用签、也不用跑学院盖章。

**范围冻结**：数学里**一个模块**（按现有材料即初中的二次函数）+ 3 种题型 + 2 类图形；只做"单题 + 一课时小卷"，整卷大考进 roadmap。
范围按"模块"收窄，不按"学段"收窄——项目的目标是数学出题，初中只是当前这批材料所在的学段。

## 5. 材料清单（作品提交）

- 申报书及承诺书（平台生成 → **主持人签字** → 扫描成 PDF；学生团队**无需盖章**，见上面的核对说明）
- 作品介绍 PDF（含作品名称、3–5 个关键词、概要、教育痛点、技术创新点、落地场景、应用成效）
- 演示视频 MP4（**不多于 10 分钟、不超过 500 MB**；必须拍到能用的产品，不能只有讲解与 PPT）
- 支撑材料（**选填**，PDF/ZIP，总大小 ≤100 MB）：设计资料、操作手册、测试摘要等
- 明确使用的 AI 工具平台（OPC 赛道要求说明来源与使用方式）
- 数据来源与合规说明（见 [06](06-决策与红线.md)）

> 申报书与作品介绍之外的材料（演示视频、支撑材料）**在平台上传，不在仓库里**；
> 作品说明的正文即 `命题组_作品介绍` 那份（PDF/Word/Markdown 三份同内容）。
