# 04 · 流程与交互

> 本项目**不是向导**（填表 → 等待 → 拿结果），而是**会话 + 一份活的制品**。老师像程序员用 Codex 那样用它。

---

## 1. 使用流程（agent loop 版）

**① 开一个会话，像跟 Codex 讲需求。**
第一轮把背景一次说清：教学进度（九上·22 章·第 2 课时）、作业卷、40 分钟、10 题、偏易、禁用动点题、导出 Word 双栏。这些成为**会话约定**（相当于 `AGENTS.md`），后面不必重复。

**② 它开始干活，而且全程可见。**
界面是一条可展开的工作记录：`bank.search 命中 37 条`、`graph.query 前置闭包`、`sympy 构造验证通过`、`figure.render → 缩略图`、`submit 题 1 → 闸门：边界 ✅ 查重 0.06 ✅`。**点进去能看细节**：为什么拒掉一条、构造参数是多少、那张图长什么样。

**③ 产物逐条流出来，不是最后一起给。**
第 1–3 题先出来，老师**立刻**可以说"第 2 题图重画，标注别压在线上"。不必等 10 题出齐再返工。

**④ 随时插话、随时打断。**
方向不对就打断（"动点题不用禁，是我写错了"），它调整后继续，已有产物不丢。
（框架现成语义：`send(message, { ifBusy: 'join' | 'defer' | 'reject' })`——`join` = 插进当前回合的下一步。）

**⑤ 出齐之后，会话不结束——这是重点。**
继续提需求："第 3 题换综合一点的"、"再补两道解答题"、"整体难度再降一档"、"顺序调一下"。每次都是**对同一份卷子的编辑**，只重做受影响的题位，其余不动。

**⑥ 每次改动都有可读的差异。**
v1 → v2 哪几题换了、为什么换；可回退到任意版本。
**"换一道"按钮本质就是发一条"第 3 题换一道"的消息**——按钮只是预设指令的快捷方式。

**⑦ 终审 = commit。**
逐题 ✅ 或改，最后"定稿导出"。**导出 / 发布 / 写回题库这类有副作用的动作要显式确认。**

**⑧ 记录留存。**
需求、每次被闸门拒绝的原因、每处人工确认（谁、何时）构成可追溯记录。下次可以基于这次继续："还是这个班，比上次稍难。"

## 2. 为什么是这个形状：程序员写代码的类比

| 编码 | 本项目 |
|---|---|
| repo / 工作区 | **一份卷子** |
| 文件 | 一道题（题位） |
| 改一个文件 | 局部重做某一题 |
| 重构 | 换题型组合、调难度分布 |
| 类型检查 / CI / 测试 | **闸门链**（不可调度） |
| 中断 + 插话 | 打断 agent、改口 |
| diff | 版本间题目的增删改 |
| revert | 回退到 v2 |
| AGENTS.md | 会话约定（进度、班级、禁用清单） |
| commit / 发版 | 人工终审签字 + 导出 |
| 长跑后台任务 | 丢着让它跑，去看别的 |

**由这张表直接推出的四条设计要求**：

1. **制品必须可增量编辑**：卷子 = 题位 + 版本；必须支持**按题位局部重做**（改一行）与**结构改动**（重构）两种粒度。
2. **必须有会话状态**：约定、已确认决定、未解决疑点。疑点不能静默丢弃。
3. **必须有 diff / 版本 / 回滚**。
4. **必须支持插话与中断**（借用 `ifBusy` 语义，不要自己造）。

## 3. agent 什么时候停

不靠预算刹车（已否决，[06](06-决策与红线.md) ADR-0006），而由**结构**决定：

- 闸门全部通过 → 提交成功，该题位完成；
- 判定为**构造不可行**（参数退化、目标无解）→ 该题位作废并说明原因；
- 老师插话 / 打断 → 立即改道。

## 4. 局部重做的约束

重做某一题位时，必须**保持该题位的蓝图约束不变**（知识点 · 认知水平 · 题型 · 难度区间 · 分值）。
若老师的要求与蓝图冲突（"换一道难的"），系统应当**提出改蓝图**，而不是偷偷破坏一致性。

## 5. 界面分区

| 区域 | 内容 |
|---|---|
| 左 | 会话列表 |
| 中 | 对话 + 命题组工作记录（可展开的每一步）+ 输入框与快捷指令 |
| 右 | 三个页签：**卷子**（题位卡片流 + 徽章 + 证据 + 单题操作）、**知识网络**（覆盖视图）、**证据**（逐题闸门明细 + 生成轨迹） |
| 顶 | 会话约定 chips + 版本切换 + 定稿导出 |

**徽章**：`符号 ✅` `知识边界 ✅` `查重 0.08` `难度 0.72` `原创度 93%` `图形 ✅` `人工确认 · 老师 21:14` `待复核 ⚠️`。
**卷头一行小字**（信任的载体）：*本卷生成中被闸门拦下 5 次（2 次超纲 · 1 次多解 · 2 次图形误导），已自动重做。*

布局参考：[`../../preview/index.html`](../../preview/index.html) —— **静态示意，仅供对齐布局，不是前端起点**。

## 6. 两个必须保留的演示瞬间

1. **故意让一道题出错，被闸门当场抓住并自动重做**——评委看"完美的结果"会怀疑，看"被抓住的错误"才相信系统是真的。
2. **现场改 `cordis.yml` 一条配置（题型/难度/禁用清单），热重载立刻生效**——比十页 PPT 都管用。
