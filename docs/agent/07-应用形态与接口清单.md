# 07 · 应用形态与接口清单

> 这份文件回答一个问题：**把它当一个真应用交付，还差什么。**
> 界面按它做，后端按它补；缺口写在最后，别假装看不见。

---

## 1. 一条完整的使用旅程

```
开一个会话（班级 / 进度 / 禁用清单）
  → 让命题组干活（agent 内环：查素材、构造、写题面、自查、提交）
      ↳ 过程中可打断、可插话、可只改某一道题
  → 看卷子（题位、图、难度、证据徽章；不合格的标"待复核"）
  → 逐题处理（换一道 / 只重做这题 / 我确认）
  → 终审签字 → 定稿导出（Word 可打开）→ 冻结归档
```

## 2. 七块界面区域与数据来源

| 区域 | 内容 | 数据来源 |
|---|---|---|
| 顶栏 | 会话标题、班级、满分/时长、**能力状态**（模型/语料/联网）、明暗、导出 | `GET /api/settings` + 会话 |
| 左栏 | 会话列表（多会话）、新建、会话约定（进度/班级/禁用清单，可编辑） | `GET/POST /api/sessions`、`PATCH /api/session` |
| 中栏 | 工作记录：用户气泡 + agent 工具行 + 闸门行（实时）；输入框可打断/插话 | `POST /api/run`、SSE `run:step` |
| 右栏·卷子 | 题位卡片（题干/图/难度/分值/徽章）、单题操作、版本切换与 diff | `GET /api/session`、`POST /api/session/regenerate`、`POST /api/session/confirm` |
| 右栏·知识网络 | 覆盖/已学/未学三层视图 | `GET /api/state`（knowledge） |
| 右栏·证据 | 逐题闸门明细 + 原创度 + 生成轨迹 | `GET /api/state`、SSE |
| 状态面板 | 模型/语料统计/联网开关（只读，改配置去 `cordis.yml`） | `GET /api/settings` |

## 3. 两个不可协商的状态迁移

| 迁移 | 谁允许 | 落点 |
|---|---|---|
| `needs_review` → `verified` | **只能由人**（R4） | `POST /api/session/confirm { itemId, by }`，写 `review.confirmedBy/At`，并入会话轨迹 |
| 任意改动（组卷 / 局部重做） | 冻结后**一律拒绝**（R3） | `POST /api/session/freeze` 之后所有写操作返回 409 |

## 4. 接口清单

| 能力 | 接口 | 状态 |
|---|---|---|
| 会话列表 / 新建 / 切换 | `GET/POST /api/sessions`、`POST /api/session/switch` | ✅ |
| 会话约定编辑 | `PATCH /api/session` | ✅ |
| 组卷（产生新版本） | `POST /api/session/assemble` | ✅ |
| 局部重做某题位 | `POST /api/session/regenerate` | ✅ 守蓝图约束 |
| 版本列表 / diff | `GET /api/session`（含 versions + diff） | ✅ 每版带完整绑定，界面能翻历史 |
| 人工确认签字 | `POST /api/session/confirm` | ✅ 写 `review` + 事件 |
| 冻结 | `POST /api/session/freeze` | ✅ 之后写操作 409 |
| 导出（Word 可打开） | `GET /api/export?format=html\|md` | ✅ HTML 内嵌 SVG 图 |
| 能力状态与统计 | `GET /api/settings` | ✅ 模型/语料/联网/构造器/闸门 |
| agent 工作台运行 | `POST /api/run` | ✅ 已有 |
| 实时事件 | `GET /api/stream`（`stored` / `rejected` / `run:step`） | 本轮补 `run:step` |
| 题库 / 图谱状态 | `GET /api/state` | ✅ 已有 |
| 单题生成（调试用） | `POST /api/generate` | ✅ 已有 |

## 5. 这一轮之后仍然缺的（诚实清单）

- **真 Word（.docx）导出**：先用 HTML（Word 能打开、图内嵌、公式可读），
  .docx 需要额外依赖，等排版定稿再说；
- **局部重做的"理由"字段**：界面上还没有让老师随手写一句"为什么换"（ADR 里已定，UI 未做）；
  这关系到版本冲突时的自愈能力；
- **多用户与权限**、**云端**、**沙箱**：阶段一不做（见 [06](06-决策与红线.md)）；
- **错因库 / 压缩 / token 计量**：仍是 roadmap。
