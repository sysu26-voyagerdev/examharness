# 07 · 应用形态与接口清单

> 这份文件回答一个问题：**把它当一个真应用交付，还差什么。**
> 界面按它做，后端按它补；缺口写在最后，别假装看不见。

---

## 1. 一条完整的使用旅程

```
知识库页：上传一份真题/教研整理件（原料）→ 让 agent 整理 → 抽出来的题进语料
  ↓
会话页：新建会话（班级 / 进度 / 蓝图 / 归属分组 / 用哪个知识库）
  ↓
工作台：让命题组干活（agent 内环：查素材、构造、写题面、自查、提交）
      ↳ 过程中可打断、可插话、可只改某一道题
  → 看卷子（题位、图、难度、证据徽章；不合格的标"待复核"）
  → 逐题处理（换一道 / 只重做这题 / 我确认）
  → 终审签字 → 定稿冻结 → 导出（Word 可打开）
设置页：模型 / 联网 / 语料目录 / 会话默认值 / 查重阈值——改完立刻生效
```

## 2. 四个页面（hash 路由，不引路由库）

| 页面 | 地址 | 内容 | 数据来源 |
|---|---|---|---|
| **工作台** | `#/work` | 左：会话列表（切/新建/管理）· 中：工作记录 + 输入框（跑起来时变成"插话"）· 右：卷子 / 知识网络 / 证据 / **工作区** | `/api/sessions`、`/api/session`、`/api/state`、`POST /api/run`、`/api/run/{interject,stop}`、`/api/workspace`、SSE |
| **会话** | `#/sessions` | 分组（建/重命名/移入）· 新建会话表单（标题/班级/进度/蓝图/分组/知识库）· 打开 · 改约定 | `GET/POST /api/sessions`、`POST/PATCH /api/groups`、`POST /api/session/group`、`PATCH /api/session` |
| **知识库** | `#/knowledge` | 上传原料（选文件或粘贴）· 批次列表与状态 · **分片预览** · **让 agent 整理**（过程实时可见、可插话、可叫停）· 整理留下什么（工作区） | `GET /api/kb`、`POST /api/kb/upload`、`GET /api/kb/preview`、`POST /api/kb/ingest` |
| **设置** | `#/settings` | **模型**（API 地址 / API 密钥[只写不读] / 模型 / 获取可用模型）· 联网开关 · 语料目录 · 会话默认值 · 查重阈值 · 只读运行期事实 | `GET/PATCH /api/settings`、`POST /api/settings/credential`、`POST /api/settings/models` |

顶栏（常驻）：品牌、四页导航、当前会话标题与满分/时长/待复核、能力状态（模型/语料/联网）、明暗、导出。

## 3. 两个不可协商的状态迁移

| 迁移 | 谁允许 | 落点 |
|---|---|---|
| `needs_review` → `verified` | **只能由人**（R4） | `POST /api/session/confirm { itemId, by }`，写 `review.confirmedBy/At`，并入会话轨迹 |
| 任意改动（组卷 / 局部重做） | 冻结后**一律拒绝**（R3） | `POST /api/session/freeze` 之后所有写操作返回 409 |

## 4. 接口清单

| 能力 | 接口 | 状态 |
|---|---|---|
| 会话列表 / 新建 / 切换 | `GET/POST /api/sessions`、`POST /api/session/switch` | ✅ 列表带 groups + defaults |
| 会话分组 | `POST/PATCH /api/groups`、`POST /api/session/group` | ✅ 老存档缺字段时在加载处补齐 |
| 会话约定编辑 | `PATCH /api/session` | ✅ 只针对**当前**会话 |
| 组卷（产生新版本） | `POST /api/session/assemble` | ✅ |
| 局部重做某题位 | `POST /api/session/regenerate` | ✅ 守蓝图约束 |
| 版本列表 / diff | `GET /api/session`（含 versions + diff） | ✅ 每版带完整绑定，界面能翻历史 |
| 人工确认签字 | `POST /api/session/confirm` | ✅ 写 `review` + 事件 |
| 冻结 | `POST /api/session/freeze` | ✅ 之后写操作 409 |
| 知识库上传 / 预览 / 整理 | `GET /api/kb`、`POST /api/kb/upload`、`GET /api/kb/preview`、`POST /api/kb/ingest` | ✅ 整理是一轮 agent 循环（立刻回 runId，过程走 SSE） |
| agent 循环控制 | `POST /api/run`（202 + runId）、`POST /api/run/interject`、`POST /api/run/stop`、`GET /api/runs` | ✅ 同一时刻一轮；插话在下一步生效 |
| 工作区 | `GET /api/workspace`、`GET /api/workspace/file` | ✅ in/tmp/out 可列可读（二进制只标注） |
| 设置读写（按路径） | `GET/PATCH /api/settings`、`POST /api/settings/credential`、`POST /api/settings/models` | ✅ 脱敏 + 路径化补丁 + 修订号冲突 |
| 密钥 | 只写不读（`POST /api/settings/credential`） | ✅ 值从不回传；存 data/credentials.json（0600） |
| 导出（Word 可打开） | `GET /api/export?format=html\|md` | ✅ HTML 内嵌 SVG 图 |
| agent 工作台运行 | `POST /api/run` | ✅ |
| 实时事件 | `GET /api/stream`（`stored`/`rejected`/`confirmed`/`run:step`/`kb:changed`/`settings:changed`） | ✅ |
| 题库 / 图谱状态 | `GET /api/state` | ✅ |
| 单题生成（调试用） | `POST /api/generate` | ✅ |

## 5. 这一轮之后仍然缺的（诚实清单）

- **真 Word（.docx）导出**：先用 HTML（Word 能打开、图内嵌、公式可读），
  .docx 需要额外依赖，等排版定稿再说；
- **局部重做的"理由"字段**：界面上还没有让老师随手写一句"为什么换"（ADR 里已定，UI 未做）；
  这关系到版本冲突时的自愈能力；
- **PDF / 扫描件**：上传仍只收文本类（`.txt/.md/.csv/.jsonl`），但 agent 可以在工作区里
  用 `.venv` 的 pdfplumber / `pdftotext` 把 PDF 转成文本再抽题；**扫描件 OCR** 依赖
  tesseract（系统包），效果不保证——没转成功就如实报告；
- **`preview/index.html` 只覆盖工作台**：会话/知识库/设置三页沿用同一套 token（ADR-0015），
  但还没有对应的静态草图——视觉契约目前以工作台那张为准；
- **多用户与权限**、**云端**、**沙箱**：阶段一不做（见 [06](06-决策与红线.md)）；
- **错因库 / 压缩 / token 计量**：仍是 roadmap。
